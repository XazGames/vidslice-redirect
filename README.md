# VidSlice

Обычный сайт с двумя инструментами: резак видео и сжатие фото. Всё работает в браузере, файлы никуда не загружаются.

Публичный адрес - `https://vidslice.run.place`.

## Страницы

- `/` - выбор инструмента.
- `/editor.html` - простой редактор видео.
- `/full-editor.html?view=editor` - большой редактор, который был раньше: фрагменты, музыка, звук и проекты.
- `/photo.html` - сжатие фото.
- `/404.html`, `/error.html` - оформленные ошибки.

Один и тот же эффект от курсора (светящийся шар и поле точек) подключён на всех страницах. На главной, в обоих редакторах и в сжатии фото есть переключатель темы и кнопка аккаунта. Тема запоминается в браузере, вход по коду работает как локальное демо без отправки писем.

## Файлы

- `src/app.js`, `src/app.css` - исходники простых страниц.
- `full-editor.html`, `assets/css/full-editor.css`, `assets/js/full-editor.js` - сохранённый большой редактор.
- `site/`, `github-pages/` - одинаковые копии готового сайта. Активная публикация идёт из `github-pages/`.
- `protect-assets.ps1` - копирует исходники в обе папки.
- `serve.ps1` - локальный сервер без зависимостей.
- `vendor/ffmpeg/` - локальный движок ffmpeg.wasm для экспорта MP4.

## Локальный запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Откройте <http://localhost:8080>.

Статическую копию можно проверить так:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -SiteDir github-pages
```

Просто открыть `index.html` двойным щелчком не получится: браузер блокирует Web Worker с `file://`. Нужен HTTP-сервер.

## Что умеет редактор видео

- загрузить MP4, MOV, WebM, MKV или другой формат, который открывает браузер;
- видео показывается сверху, область загрузки остаётся доступной для замены файла;
- выбрать начало и конец фрагмента ползунками и видеть оставшийся кусок на отдельной шкале;
- выбрать качество: как в исходнике, 1080p, 720p или 480p;
- включить сильнее сжатие;
- собрать MP4 через ffmpeg.wasm и скачать результат;
- кнопкой «Полный редактор» открыть старую большую версию со всеми возможностями.

## Что умеет сжатие фото

- JPEG, PNG и WebP;
- качество 10-95% и ограничение стороны до 2560, 1920 или 1280 px;
- если выбранный формат делает файл больше, подбирается меньший, а если уменьшить не удалось, скачивается исходник;
- размер до и после, экономия в процентах, скачивание готового файла.

## Изменение кода

Правьте `src/app.js` и `src/app.css`, затем синхронизируйте копии:

```powershell
powershell -ExecutionPolicy Bypass -File .\protect-assets.ps1
```

Проверка синтаксиса:

```powershell
tools\node\node-v22.11.0-win-x64\node.exe --check src\app.js
```

Публикация идёт через авторизованную вкладку GitHub в браузере: репозиторий `XazGames/vidslice-redirect`, ветка `main`. После загрузки файлов проверьте `https://vidslice.run.place/`.

Серверная проверка Turnstile и отправка писем не используются: код входа показывается на экране. Сохранение проектов работает только в полном редакторе.
